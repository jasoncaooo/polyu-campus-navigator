# PolyU Campus Navigator — portfolio overview

A team-built multilingual campus navigation assistant combining a React/TypeScript interface with a Python routing and dialogue engine.

- A* and uniform-cost search over campus walkway data, with closures and stair preferences.
- Optional tool-calling language model and embedding-based place search, with deterministic offline fallbacks.
- Campus knowledge retrieval, 2.5D map, and English, Mandarin and Cantonese voice interfaces.
